# AccessPro architecture

A TanStack Start / React 19 marketing website and application intake. Preserve its warm ivory and forest-green palette, editorial Georgia headings, DM Sans text, Manrope brand, architectural photography, responsive layout, and reduced-motion behavior.

## Key directories

- `src/components/MarketingPage.tsx`: landing page, FAQs, homeowner enquiry dialog.
- `src/components/Shared.tsx`: header/footer, regional preferences, image URLs.
- `src/routes/`: home, professional registration, standalone facial route, privacy, root document. The underscore in `onboarding_.facial.tsx` prevents nesting within the registration form.
- `src/styles.css`: Tailwind import and responsive visual system.
- `src/data/site.ts`: page/share metadata. Do not add an OG image.
- `public/img/`: real architectural photography served through Image CDN.
- `db/`: schema and lazily created Netlify Database client.
- `netlify/functions/register.mts`: same-origin POST intake, validation, persistent throttling, private file storage, application insertion, optional Sheets delivery.
- `src/lib/sheets.server.ts`: server-only Google authorization and supplied Sheet destination. Never import into client components.
- `netlify/functions/cleanup-limits.mts`: scheduled throttle expiration.
- `netlify/database/migrations/`: platform-applied Drizzle migrations.
- `infrastructure/private-documents.yaml`: unprovisioned AWS CloudFormation template, separate from runtime storage.

## Conventions and boundaries

Use TypeScript and validate on the server. Keep secrets in runtime configuration. Never log PII, documents, signed URLs, credentials, or tokens. Use Netlify Database with `drizzle-orm@beta` and `drizzle-kit@beta`; generate migrations from the schema with descriptive names. Do not apply migrations manually. Keep documents private. Do not send files, storage keys, or access credentials to Google Sheets.

Applications start in `initial_review_pending`. No live document verification, biometric processing, authenticated accounts, verification emails, or smart-lock provisioning is configured. Never present a document upload as a verified identity or simulate building access. Consult README before extending the flow. Sheets delivery is synchronous and optional, with pending status on failure; it needs reconciliation rather than blind retries.

Only country preference belongs in localStorage. Browser APIs belong in effects and event handlers. US/CA/GB/AU use English regional conventions. French hero copy is limited, not a full localization claim.

TanStack route types are generated by the platform. This run prohibits local build, test, dev-server, and type-check commands. Review edited files and leave validation to the deployment pipeline. Do not inspect `.git`, commit, or create pull requests.
